# 🛰️ Satellite Orbit Simulation

## Overview

Satellite Orbit Simulation is a web-based application that visualizes the motion of a satellite around Earth using basic orbital mechanics principles. The project demonstrates how satellites maintain orbit due to the balance between gravitational force and orbital velocity.

This simulator provides an interactive and educational way to understand satellite motion through real-time animation and visualization.

---

## Features

- 🌍 Earth-centered orbit visualization
- 🛰️ Real-time satellite motion animation
- 📏 Adjustable satellite altitude
- ⚡ Orbital velocity calculation
- ⏱️ Orbital period calculation
- 🎨 Interactive and user-friendly interface
- 📊 Real-time display of orbital parameters

## How It Works

The simulation is based on Newton's Law of Gravitation and orbital mechanics.

### Gravitational Force

F = GMm/r²

### Orbital Velocity

v = √(GM/r)

### Orbital Period

T = 2π√(r³/GM)

Where:

- G = Gravitational Constant
- M = Mass of Earth
- r = Distance from Earth's center
- v = Orbital Velocity
- T = Orbital Period
